# pymongo-api

## Как запустить

Перейти в директорию `sharding-repl-cache`

```shell
cd sharding-repl-cache
```

Запускаем mongodb и приложение

```shell
docker compose up -d
```

### Инициализация mongodb через make
Запускаем инициализицию и заполнение mongodb тестовыми данными

```shell
make init-mongo
```

### Инициализация mongodb вручную

Инициализация реплик сервера конфигурации и шардированных реплик

```shell
./scripts/mongo-init-replicas.sh
```

Инициализация роутера mongodb

```shell
./scripts/mongo-init-router.sh
```

Если вы запускаете инициализацию вручную роутера возможно после инициализации сервера конфигурации, что может занять время.
При запуске `./scripts/mongo-init-router.sh` вы можете получить ошибку `MongoNetworkError: connect ECONNREFUSED 127.0.0.1:27020`.
Нужно дождаться пока проинициализируется сервер конфигурации, обычно это занимает около 10 секунд, и запустит скрипт снова. Предпочтительным является запуск инициализации через `make`.

## Как проверить

### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8080

### Если вы запускаете проект на предоставленной виртуальной машине

Узнать белый ip виртуальной машины

```shell
curl --silent http://ifconfig.me
```

Откройте в браузере http://<ip виртуальной машины>:8080
